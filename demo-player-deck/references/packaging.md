# 打包與發佈

## 兩個版本

| 版本 | 內容 | 用途 |
|---|---|---|
| 線上 | index.html＋壓縮過的影片（同檔名） | 發佈成 HTML Artifact 或靜態網站，分享連結 |
| 離線 | index.html＋原始影片，放同一個資料夾再壓成 zip | 現場沒網路、或要交給別人帶走 |

```sh
scripts/package_deck.sh deck.html film.mp4 out/
# CRF=26 預設；KEEP_AUDIO=1 保留音軌；MAX_H=1080 最高解析度
```

預設拿掉音軌：簡報現場通常由講者說話，配樂會搶聲音。2026-10 的案例是 113 秒 1080p，43.7 MB 壓到 15.2 MB。

離線版的中文字型從 Google Fonts 載入，沒網路時會退回系統字型（PingFang TC），版面不會壞，字重略有差異。

## 發佈成 HTML Artifact

- 影片用 Artifact 的 `files` 跟 index.html 一起發佈，路徑對上 `data-video`。檔案上限 15 MB（二進位），超過就調高 CRF 或降解析度。
- 不要用簡報編輯器（Slides 類型）做這種簡報：它放不進互動播放器。2026-10 第一版就是卡在這裡才改成 HTML。
- Artifact 預設私人，分享前先確認影片裡的研究素材可以公開（見 SKILL.md 的授權關卡）。能打開簡報的人都能存取影片檔。
- 同一份簡報更新時用同一個檔案路徑重新發佈，網址不變。

## 決策紀錄

簡報定稿時，另開一份決策紀錄（Claude Docs 或 Markdown 都可），四節：

1. 定稿版本：每頁的段落、標題、重點一張表。
2. 版本歷程：每一版的形式、結構、被取代的原因。
3. 關鍵決策與理由；另列刻意不採用的做法和原因。
4. 上台與分享前待確認：勾選清單，第一項放授權。

被取代的舊版 Artifact 在紀錄寫好之後就可以刪，結構已經留在紀錄裡。
