# 播放器資料格式

播放器讀 `.player` 元素上的三個屬性。內容全在屬性裡，JS 不用改。

## data-video

影片的相對路徑，例如 `demo.mp4`。線上版把影片當成發佈檔案放在 index.html 旁邊；離線版放同一個資料夾。留空時播放器用模擬時鐘跑，可以先排版、後補影片。

## data-roles

每種說明的標籤與小圓點顏色。顏色只用在小圓點，不用大面積底色。

```json
{
  "mech":  {"label": "AI 機制",            "color": "var(--dA)"},
  "ui":    {"label": "使用者操作",          "color": "var(--dR)"},
  "mix":   {"label": "AI 提出，使用者決定",  "color": "var(--dR)"},
  "brand": {"label": "片頭",              "color": "var(--dP)"},
  "outro": {"label": "片尾",              "color": "var(--dP)"}
}
```

## data-stages

一個陣列，每個元素是一個研究階段，依時間排序：

```json
{
  "name": "研究資料與編碼",
  "start": 6.5,
  "end": 32.3,
  "subs": [
    {"s": 6.5,  "e": 12.5, "k": "ui",   "c": "使用者打開專案，查看研究目的與資料。"},
    {"s": 12.5, "e": 32.3, "k": "mech", "c": "AI 逐段編碼。", "n": "畫面經剪輯，不是即時生成。"}
  ],
  "marks": [{"t": 20.0, "sym": "★", "label": "使用者在這裡選擇"}]
}
```

- `start`、`end`：秒，小數一位。還沒有時間碼的階段寫 `null`，清單上顯示「待補」，控制列會藏起來。
- `subs`：定格說明，顯示在左欄、不疊在影片上。`k` 對應 `data-roles`；`c` 是說明句；`n` 是選填的誠實註記，例如剪輯、展示圖層、不是即時生成。
- `marks`：刻度上的符號，播放到前後 1.2 秒內時顯示標籤。符號放在階段清單上，讓聽眾知道哪一段有使用者決策（★ 選擇、✎ 修改）。

## 時間碼從哪裡來

只從影片腳本或逐格確認取得，不用估的。影片腳本若有逐段時間表（例如審閱用的 script review 頁），直接轉成 `subs`。真的只能估時，在 `n` 寫明「位置為估計」，上台前校正。

## 檢查

```sh
python3 scripts/check_stages.py deck.html --video demo.mp4
```

會列出階段之間的空檔或重疊、超出階段的說明、刻度不在時間軸上、未定義的說明種類、待補的階段，以及時間軸比影片長的情況（需要 ffprobe）。
