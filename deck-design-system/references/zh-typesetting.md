# 中文斷行與排版規則（繁體中文簡報）

適用於 `iasdr` 主題的中文版。字級、行高、格線見 `iasdr-typesetting.md`；這份只講**斷行、標點、混排與寫法**。

- **實測**：2026-11-06 在 Chrome 157 實際渲染 28px Noto Sans TC 測過，結果附在 §1。
- **參考過的錯誤**：專案計畫簡報、口試簡報的實際問題，標在各條規則裡。

## 1. 斷行設定（實測結論）

同一段 11 字寬的內文，三種設定的實際斷行如下：

| 設定 | 斷行結果 | 判定 |
|---|---|---|
| `word-break: normal` + `line-break: strict` | 〔…彈性為核心的參與〕〔制度，將削弱…〕…〔設計。〕 | **採用**。遵守標點禁則，會在詞中斷行（例如「一／致」），可接受 |
| `word-break: normal` + `line-break: normal` | 與上一列相同 | 可用；`strict` 對日文小假名更嚴格，中文差異不大 |
| `word-break: keep-all` + `overflow-wrap: anywhere` | 〔制度，〕〔將削弱信眾對制度的信任〕〔；因此…〕…〔。〕 | **不得使用**。分號落到行首，句號單獨成行 |

`keep-all` 只在標點與空白處斷行；遇到比一行還長的詞組，`overflow-wrap: anywhere` 會強制在任意位置斷，結果把標點推到行首。`iasdr-deck.html` 原本用的就是這組設定，已改正（見 §9）。

**CSS 設定**

```css
[lang="zh-Hant"] .slide { word-break: normal; line-break: strict; text-autospace: normal; }
[lang="zh-Hant"] .display, [lang="zh-Hant"] .title, [lang="zh-Hant"] .big { word-break: keep-all; } /* 標題由作者指定斷點 */
.nb { white-space: nowrap; }                                                                   /* 不可拆的詞 */
```

**瀏覽器支援（Chrome 157 實測）**

| 屬性 | 支援 | 用法 |
|---|---|---|
| `text-autospace` | 支援，會自動在中英、數字之間加空白 | 只當保險；原文仍要手動加空白（§3） |
| `text-wrap: balance` | 支援 | 英文標題用；中文標題仍要手動斷行 |
| `text-wrap: pretty` | 支援 | 可用在內文，避免最後一行只剩一兩個字；對中文的效果不保證 |
| `hanging-punctuation` | 不支援 | 不要依賴標點懸掛 |

PPTX、Word、其他瀏覽器的支援不同，所以**能寫在原文裡的規則，一律寫在原文裡**，不靠 CSS 補。

## 2. 斷行規則

### 2.1 標點禁則

| 位置 | 不得出現 |
|---|---|
| 行首 | ，。、；：？！」』）】》〉…—— |
| 行尾 | 「『（【《〈 |

口試簡報 p27、p28 都有逗號單獨落在行首的情況。

### 2.2 標題由作者斷行

- **標題、大句、封面標題一律手動斷行**。斷在語意單位之間：主詞與述語之間、逗號之後、「的」之後的名詞片語之前。瀏覽器的自動斷行和 `balance` 都不保證這點。範本實測就出現過「中英／雙語」被拆開。
- **每行 ≤ 20 字，最多 2 行**。超過就改寫，不要縮小字級。口試簡報的標題多為 2 行、每行超過 20 字。
- 兩行長度要接近，或上短下長；第一行要能單獨讀懂。
- 標題結尾不加句號。

### 2.3 不可拆的詞

以下內容要包在 `.nb` 裡，或在 PPTX 裡用不斷行空白連接：

- 數字＋單位：`12 人`、`2–3 個月`、`48.6%`、`NT$ 500 萬`。
- 英文詞組與產品名：`LINE 官方帳號`、`AI 小幫手`、`People, Process, Props`。
- 專有名詞與代號：`P1`、`H2`、`Module M5`、人名、機構名。

### 2.4 孤字與寡行

- 段落最後一行至少 2 個字，加上句末標點。
- 卡片內的短段落（≤ 3 行）如果最後一行只剩一兩個字，改寫或調整卡片寬度。不要靠縮字距硬塞。

## 3. 中英混排

| 規則 | 正確 | 錯誤 |
|---|---|---|
| 中文與英文之間留半形空白 | 使用 LINE 官方帳號 | 使用LINE官方帳號 |
| 中文與數字之間留半形空白 | 完成 12 場訪談、2026 年 | 完成12場訪談 |
| 全形標點前後不加空白 | 採用 AI，提升效率 | 採用 AI ，提升效率 |
| 符號與數字之間不加空白 | 48.6%、NT$ 500 萬 | 48.6 % |
| 英文保留原本的大小寫 | iPad、LINE、GitHub | Ipad、Line、Github |

- **字型**：中文裡的英文與數字用英文字型（Manrope／Inter），中文落到 Noto Sans TC。CSS 字型堆疊寫成 `"Manrope","Noto Sans TC"`。PPTX 要分別設定拉丁字型與東亞字型。
- **一定要宣告語言**：`lang="zh-Hant"`，讓字型選用繁體字形。
- **字型用本機檔**：`templates/fonts/`（`scripts/fetch-fonts.sh`）；樣式裡本機字型排第一，Google Fonts 只當備援。
- **避免字型被替換**：專案計畫簡報與口試簡報的 PDF 都嵌入了 SimSun、MS PMincho、Times New Roman，表示匯出時字型被替換。口試封面的英文副標就顯示成 Times New Roman。匯出 PDF 前要確認本機已安裝字型，再用 `pdffonts` 檢查嵌入的字型清單。

## 4. 標點

| 項目 | 規則 |
|---|---|
| 中文句子 | 全形標點：，。、；：？！ |
| 英文句子 | 半形標點；英文句子夾在中文段落裡時，句內維持半形 |
| 引號 | 用「」，引號內再引用用『』；不用 “ ” |
| 括號 | 中文內容用全形（）；純英文或數字的補充也用全形，例如「（2024）」 |
| 書名、篇名 | 書名《》、篇名〈〉 |
| 刪節號 | ……（兩個，佔兩個字寬） |
| 破折號 | ——（兩個，佔兩個字寬） |
| 範圍 | 2–3 個月（en dash）或「2 至 3 個月」，全篇統一一種 |
| 列舉 | 用頓號「、」；英文列舉用半形逗號 |
| 標題 | 不加句號；提問頁可用問號 |
| 內文 | 完整句子加句號；條列的短語不加 |
| 驚嘆號 | 簡報中不用 |

**最常見的錯誤**：中文句子裡用半形逗號，例如「影響, 數位」。口試簡報全篇都是這樣。

## 5. 對齊

- **內文一律靠左對齊**，不要左右對齊。中英混排時左右對齊會撐開字距。
- **置中只用於 ≤ 2 行的短句**：引言、結論、大數字。超過 2 行的段落不要置中，例如口試 p18、p21 置中了 4 行段落。
- 表格：文字欄靠左，數字欄靠右並使用等寬數字。

## 6. 強調

- **一頁只用一種強調方式**：字重 700，或 `accent` 色，二選一。
- **標題上色**：內容頁的 h1 可以把**一段**關鍵詞改成 `accent` 色，寫成 `<span class="hl">`，例如「檢視設計知識的<span>實際成效與可遷移性</span>」。上色的是這一頁要聽眾記住的那半句，中文不超過 12 字。標題一旦上色，這一頁的內文就不再另用色字；引言卡裡的粗體關鍵句不受限（lint R28）。色塊頁（封面、提問、結語）的大字不上色。
- **引言卡**：一則引言只粗體一句關鍵話，其餘維持一般字重。
- **每段最多強調一處**。口試簡報同時用了粗體、橘色、棕色、紅色。
- 中文不用斜體、底線、全大寫。
- 強調的是關鍵詞，不是整句。

## 7. 中英雙語同頁

- **中文是主文、英文是輔助**：英文字級是中文的 0.6–0.72 倍。小標用 0.72 倍；封面英文副標用 subtitle 的 0.7 倍。
- 英文不使用襯線字（例如 Times New Roman），與中文字型的筆畫粗細不協調。
- 英文小標放在中文後面，留一個字寬的間距：`排版原則 Typesetting`。
- 中英兩版的同一頁，要保留相同的段落編號與代號（P1、H2），方便對照。

## 8. 數字與單位

- 一律用半形阿拉伯數字；不用全形數字或國字數字（「三項」這類量詞例外）。
- 千分位加逗號：`4,800`、`12,480`。
- 年份：`2026 年`；年月：`2026 年 1 月`；不寫「115 年」，除非是官方文件原文。
- 百分比保留到小數一位；同一頁的小數位數要一致。

## 9. 範本的改正

`templates/iasdr-deck.html` 原本對中文內容設 `word-break: keep-all; overflow-wrap: anywhere`，依 §1 實測會讓標點落到行首。

改為：
- **內文**：`normal` + `strict` + `text-autospace`。
- **標題**：保留 `keep-all`，並由作者手動斷行。

## 10. 可以自動檢查的項目

這些規則可以寫成 lint，在產出前擋下：

| 檢查 | 方法 |
|---|---|
| 中文句子裡的半形逗號、句號 | 規則式：中文字後接 `,` 或 `.` 再接中文字 |
| 中英、中數之間缺空白 | 規則式：中文字緊鄰英文字母或數字 |
| 標點落在行首 | 渲染後逐行檢查每行第一個字 |
| 標題每行字數、行數 | 渲染後計算 h1、display 的行數與每行字數 |
| 置中段落超過 2 行 | 渲染後檢查 `text-align: center` 的元素行數 |
| 字型被替換 | HTML 用 `document.fonts` 檢查實際載入的字型；PDF 用 `pdffonts` 檢查是否出現 SimSun、MS Mincho、Times New Roman |
| 一頁超過一種強調色 | 統計每頁強調元素的顏色種類 |
| 頁尾文獻格式 | lint R26：最多 2 行、不碰頁碼、APA 文獻要有 `<i>`、英文期刊是斜體、中文不得斜體 |

## 11. 頁尾參考文獻（APA 7）

投影片底部的完整文獻放在**來源列（C05）**：左下，距底 32，micro 18px、`text2`，右緣距頁面右邊 160，避開頁碼。

**樣式**

| 項目 | 英文文獻 | 中文文獻 |
|---|---|---|
| 期刊名＋卷數 | 斜體：*Design Studies, 20*(1) | **粗體**：**設計學報，12**（3）。中文不用斜體（§6） |
| 標點 | 半形：`. , ( )` | 全形：`。，（）` |
| 作者與年份 | `Cross, N. (1999).` | `王小明（2020）。` |
| 頁碼範圍 | en dash：`25–39` | en dash：`45–67` |

寫法：期刊名＋卷數一律包在 `<i>` 裡，樣式由文獻的語言決定，不由簡報語言決定。

```html
<!-- 英文簡報 -->
<p class="src">Cross, N. (1999). Natural intelligence in design. <i>Design Studies, 20</i>(1), 25–39.</p>
<!-- 中文簡報：英文文獻加 lang="en"，才會是斜體；中文文獻的 <i> 自動變粗體 -->
<p class="src"><span lang="en">Cross, N. (1999). Natural intelligence in design. <i>Design Studies, 20</i>(1), 25–39.</span><br>
王小明（2020）。篇名。<i>期刊名稱，12</i>（3），45–67。</p>
```

**數量**
- 來源列**最多 2 行**，大約就是 2 筆文獻。
- 超過時，頁內改用文內引用，例如 `(Cross, 1999)` 或 `（王小明，2020）`，完整文獻放到最後的參考文獻頁。
- 不加「資料來源：」或「Source:」標籤，APA 格式本身就看得出是出處。

**字級的限制**：18px 換算到 PPTX 約 9pt，在投影機上只有前排看得清楚。來源列是給事後看投影片的人查證用的。要讓聽眾當場讀到的引用，放在卡片右上的引用（C11，caption 22／20px）。
