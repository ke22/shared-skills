# 版型清單 v2（敘事版型）

## 定義

```
版型（一段敘事，回答聽眾的一個問題）
  └ 變體（同一段敘事的不同表現方式，依內容的形狀選）
      └ 元件（積木，見 components.md）
```

- **版型**用敘事命名，不用排版形狀命名。
- **變體**依內容的形狀選：項目數、資料類型（數字、文字、圖、照片）、密度、放在簡報的哪個位置。
- **元件**名稱與 `components.md` 一致，括號內是元件代號。
- **視覺基礎**是 `templates/iasdr-deck.html` 與 `tokens.json` 的 `themes.iasdr`。
- **中文斷行與排版**見 `zh-typesetting.md`。

- **有**：範本已有。

- **P2**：常用但可晚做。
- **P3**：工作台的模式有規範，但三份參考簡報都沒有範例。
