# IASDR 主題：版型與中英排版規格

視覺標準取自 IASDR 2025 的研討會簡報（16 頁，1920 × 1080）。英文版沿用原檔，繁體中文版是依同一套格線另外推導的排版系統。

- **唯一數值來源**：`../tokens.json` 的 `themes.iasdr`。
- **可直接使用的範本**：`../templates/iasdr-deck.html`，中英各 10 種版型。
- **一致性檢查**：`scripts/check-tokens.mjs` 會比對範本與 tokens，不一致就回報失敗。

## 0. 數值的來源與可信度

| 標記 | 意思 | 例子 |
|---|---|---|
| **實測** | 由 PDF 渲染後取色或量像素 | 色碼、各層字的筆畫高度與行距 |
| **校正** | 原檔各頁不完全對齊，我取中位數並對齊 8px 格 | 邊界 112、標題直條 x、卡片間距 56 |
| **推導** | 原檔沒有中文；依中文排版慣例推導 | 中文字級、行高、字距、斷行規則 |
| **目視** | PDF 字型是 Figma 匯出的 Type 3 字形，沒有字型名稱 | Manrope／Inter 是依字形辨認，不是讀出來的 |

字級由「含上下伸部的筆畫高度」推估，誤差約 ±10%。若能取得原 Figma 檔，請以原檔為準並更新 `tokens.json`。

**對齊規則**
- 卡片和內容從邊界 112 開始，與標題直條對齊；標題文字則縮排 48。這是原檔的做法：直條和卡片是同一條垂直線。
- 色塊頁（封面、提問、結語）沒有標題直條，文字直接從邊界 112 開始。

## 3. 字型與中英搭配

| 角色 | 英文版 | 中文版 |
|---|---|---|
| 標題類（display、h1–h3、lead） | Manrope | Manrope ＋ Noto Sans TC |
| 內文類（body、caption） | Inter | Inter ＋ Noto Sans TC |

**字型檔放在本機**：`templates/fonts/`（`scripts/fetch-fonts.sh` 下載；三套皆 SIL OFL 1.1，`.ttf` 不進 git）。字型堆疊先用本機字型 `IASDR Manrope`／`IASDR Inter`／`IASDR Noto Sans TC`，再退回 Google Fonts，所以離線也能正確渲染（已斷網實測）。

**中文版的字型堆疊**寫成 `"Manrope","Noto Sans TC"`，這樣中文字裡的英文字母和數字會用 Manrope／Inter，中文字落到 Noto Sans TC（思源黑體）。兩版的拉丁字與數字因此長得一樣。

**混排規則（全篇只用這一套）**
1. 中文與英文、數字之間留一個半形空白：`HTML 與 PPTX`、`2026 年 11 月`、`112 px`。
2. 中文句子用全形標點：`，。；：「」（）？`；英文句子用半形標點。
3. 數字一律用半形阿拉伯數字，不用全形數字。
4. 中文不用斜體、不用全大寫；強調靠字重或顏色。
5. 英文的全大寫 kicker（`HOW SHOULD WE`）在中文版改成短句（「我們該如何」），字距加到 0.08em。
6. 中文 eyebrow 可附英文小標：`排版原則 Typesetting`。英文小標是 eyebrow 字級的 0.72 倍，顏色 `accent2`。

**實測依據（英文）**：封面標題筆畫高 128、行距 154；提問頁主句高約 102、行距 125；標題高 62、行距 71；eyebrow 高 30；卡片標題高 39；內文高 29、行距 34–36；引用高 23。

**中文字級為什麼較小**：中文字面占滿整個字身框，同樣的像素看起來比英文大、密度也高。所以標題類縮小約一成，內文維持同大但加大行高。

### 1280 × 720（PPTX）換算

全部 × 2/3：display 85／75、statement 69／61、h1 43／37、h2・h3 27／24、lead 24／21、body-l 19、body 16、caption 15／13、micro 12。邊界 75、上 48、下 53、欄寬 75、欄距 21、大圓角 27。

## 5. 行距與行長

| | 英文 | 中文 |
|---|---|---|
| 標題行高 | 1.12 | 1.3 |
| 內文行高 | 1.3–1.4 | 1.6–1.65 |
| 內文行長 | 60–75 字元（`max-width: 34em`） | 22–32 字（`max-width: 30em`） |
| 字距 | 標題負字距，內文 0 | 一律 0，內文 +0.02em |

## 6. 中文斷行與標點

1. **標題由作者指定斷點**。瀏覽器的 `keep-all` 和 `text-wrap: balance` 都無法保證在詞組處斷行，範本實測就出現「中英／雙語」被拆開。標題請用 `<br>` 斷在詞組之間，或把不可拆的詞包在 `.nb`（不換行）裡。
2. 句末標點（，。；：、」）不放在行首；開括號（「（）不放在行尾。
3. 內文用 `word-break: normal` 加 `line-break: strict`；標題用 `keep-all` 並手動斷行。**不要**對中文內文用 `keep-all` 加 `overflow-wrap: anywhere`，實測會把標點推到行首。
4. 標題最多 2 行，每行不超過 20 字；超過就改寫，不縮字。

完整的斷行、標點、混排規則與實測結果見 `zh-typesetting.md`。

**對比度限制**
- 藍底 `field` 上的白字約 4.2:1，未達一般文字的 4.5:1。藍底上只放 **24px 粗體或 32px 以上**的文字；日期、單位這類小字要放大或改到白底。
- 未選取的階段文字 `inactive` 仍帶資訊，所以維持 ≥ 3:1（大字）。
- 中文小標後的英文小標、藍圖分隔線標籤用 `text2`，不用 `accent2`（後者在 20px 只有 4.43:1）。
- 服務斷點用 `warning`（琥珀），不用 `danger`；紅色只留給真正的緊急或失敗。

## 10. 原檔的不一致，以及我怎麼處理

| 原檔現象 | 處理 |
|---|---|
| 標題左緣在 108–163px 之間浮動、直條位置不一 | 統一為直條 112、文字 160 |
| p2–p3 的標題字型和其他頁不同（較窄較重） | 全部統一用 Manrope |
| p5 圖解用了另一種字型（類似 Calibri） | 統一用 Manrope／Inter |
| 內文實測是純黑 `#000000` | 調為 `#111111` |
| p9 混用其他藍（`#258FDD`）做產品畫面 | 只在產品截圖內出現，不進 token |
| 藍底上有小字（日期約 22px） | 規定藍底文字最小 24px 粗體或 32px |

## 11. 限制與尚未做的事

- **字型辨認是目視的**。若作者提供 Figma 原檔，請以原檔為準。
- **PPTX 尚未套用**。`research-components.mjs` 仍是舊的 `research` 主題（1280 寬、舊字級）。要讓工作台產出這個風格，需要改 helper，並在 PPTX 設定東亞字型（中文 `ea` typeface 設 Noto Sans TC，拉丁字設 Manrope／Inter）。
- **照片位置只是占位**。範本沒有放任何照片。
