# zh-TW → EN Research Presentation Skill

This package contains:

- `SKILL.md` — executable workflow and translation rules
- `references/translation_registry.md` — locked terminology and research-defined labels
- `references/qa_checklist.md` — semantic and presentation QA

Traditional Chinese research presentations involving dementia care, Taiwan LTC,
HCI/service design, conversational AI, and field evaluation, for an Australian iSupport
/ international academic audience.
