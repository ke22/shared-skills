# QA Checklist

Use after translation and again after presentation polishing.

## A. Meaning preservation

- [ ] Actor preserved
- [ ] Recipient preserved
- [ ] Negation preserved
- [ ] Time preserved
- [ ] Quantity preserved
- [ ] Comparison preserved
- [ ] Cause vs association preserved
- [ ] Recommendation strength preserved
- [ ] Certainty / uncertainty preserved
- [ ] No source content silently omitted
- [ ] No unsupported interpretation added

## B. Terminology

- [ ] LOCKED terms follow registry
- [ ] Research-defined terms remain consistent across slides
- [ ] BPSD and `behaviour changes` are used according to discourse
- [ ] `family carer` / `caregiver` choice follows audience/source
- [ ] Australia-specific spelling is consistent where appropriate
- [ ] Scale names are official names
- [ ] Clinical terms are not replaced with casual paraphrases

## C. Taiwan role equivalence

- [ ] Home care worker is not presented as an Australian-equivalent occupation
- [ ] Home care supervisor is not silently remapped
- [ ] A-unit case manager is identified as a Taiwan LTC role when needed
- [ ] `clinical` is used only when actor is clinically qualified

## D. Research claims

- [ ] Pilot findings are not described as proof
- [ ] Statistical significance is only stated if reported
- [ ] Confidence is not automatically renamed self-efficacy
- [ ] Participant perception is not rewritten as objective effect
- [ ] Research-defined labels are not presented as established constructs

## E. AI governance

- [ ] `clinician-in-the-loop` is used only when governance structure supports it
- [ ] Human review and professional oversight are distinguished
- [ ] `hallucination mitigation` does not imply prevention guarantee
- [ ] Referral / escalation wording reflects actual workflow

## F. Source consistency

Check text vs figures for:
- [ ] scale names
- [ ] N / n
- [ ] versions
- [ ] dates
- [ ] values
- [ ] role labels

If inconsistent:
`SOURCE_INCONSISTENCY — human verification required`

## G. Presentation readability

Only after A–F pass:

- [ ] Headline is concise
- [ ] Sentence is speakable
- [ ] Noun stacks reduced
- [ ] Parallel structure improved
- [ ] No unnecessary literal Chinese syntax
- [ ] No meaning changed during polishing
